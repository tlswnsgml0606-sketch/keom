# 귀령학교 웹 프로토타입

이 폴더는 정적 웹페이지입니다. `index.html`, `styles.css`, `js` 폴더를 한 덩어리로 GitHub 저장소에 올리면 GitHub Pages에서 열 수 있습니다.

## 현재 되는 것

- 가입 화면과 캐릭터 생성 흐름
- 아이디 영문·숫자 조합, 비밀번호 조합 및 캐릭터 이름/키/나이 입력 검증
- 퇴치사 무기 선택과 스탯 10포인트 분배
- 스탯 10포인트 분배와 자기소개 500자 제한
- 전체맵/세부맵의 임시 점 클릭과 이전과 같은 속도의 인장 이동 애니메이션, 발자국 궤적
- 세부맵 빨간 점의 미정 설명 안내, 5초 후 사라지는 말풍선, 말하기 내역 및 기록 저장
- 기록 날짜 구분 및 검색, 채팅 탭, 알림 분류
- 계정 정보, 로그아웃/탈퇴, 스탯 설명, 전신 이미지 미리보기, 7글자 추천 코드 생성
- 모바일·태블릿 가입 정보 스크롤, 로그인 화면, 캐릭터 정보 완료 후 가입 확정
- 퇴치사 무기 선택(검·총·부적과 붓·격투가의 글러브), 민첩 스탯
- 이동점 이름 숨김, 가구를 피해 최단 경로로 움직이는 인장과 순서대로 나타났다 사라지는 발자국
- 전체맵 확대, 방 인원 묶음 표시, 테스트 계정 임시·임시 2의 맵 위치 표시
- 맵에서 @이름 추천 목록과 로컬 귓속말 시제품, 채팅 계정/메시지 검색
- 지정한 분 뒤에 깨어나는 수면 시제품, 수락·거절 편지 도장 결과, 팀원 길게 누르기 후 방출 편지 작성

## GitHub Pages에 올릴 때

저장소의 최상위에 `index.html`, `styles.css`, `js` 폴더가 오도록 이 폴더 안의 파일을 올리세요. GitHub 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/(root)`로 선택하면 됩니다.

## 현재 데이터 저장 범위

이 프로토타입은 계정 프로필, 캐릭터, 기록, 맵 위치, 추천 코드 등을 해당 브라우저의 `localStorage`에 저장합니다. 로그인 흐름 확인을 위해 비밀번호는 PBKDF2 해시 형태로 저장하지만, 이는 서버 인증이 아닌 브라우저 시제품입니다. **실제 사용 중인 비밀번호를 입력하지 마세요.** 데이터는 이 브라우저에서만 유지되고 다른 사람과 공유되지 않습니다.

가입 아이디는 영문과 숫자를 모두 포함해야 하며 그 외 문자는 사용할 수 없습니다. 비밀번호는 8~16자이고 영문·숫자·특수문자를 모두 포함해야 하며, `abc`나 `123` 같은 연속 문자열과 아이디와 연속 3자 이상 겹치는 문자열을 제한합니다. 캐릭터 이름은 한글/영어, 키(cm)와 나이는 숫자만 허용합니다.

로그아웃하면 계정과 게임 데이터는 남고, 같은 브라우저에서 다시 로그인할 수 있습니다. 탈퇴하면 계정·캐릭터·기록·맵 위치 등 게임 데이터가 삭제되고, 해당 브라우저에서는 7일 동안 새 가입이 제한됩니다. 탈퇴한 아이디와 비밀번호 조합을 다시 막기 위해 별도 저장소에 해당 자격 증명 검증 해시만 보존합니다. 이 제한은 현재 브라우저의 저장소에만 적용되며 서버 수준의 보안/가입 제한이 아닙니다.

초대 코드는 현재 7글자 영문 형식만 확인합니다. 실제로 운영자가 발급한 코드인지 검증하거나 여러 사용자의 데이터를 안전하게 동기화하려면 서버와 데이터베이스가 추가로 필요합니다. GitHub Pages는 정적 파일만 제공하므로, 실제 공개 운영 전에는 인증·초대 코드·채팅·게임 규칙을 서버에서 검증하도록 연결해야 합니다.

## 실제 멀티플레이어 연결 상태

js/sync.js에는 서버 연결 어댑터 경계가 있습니다. GHBackendAdapter는 publish(topic, payload)와 subscribe(topic, callback)을 제공하도록 설계되어 있고, 현재 구현은 어댑터가 없으면 로컬 전용으로 처리합니다. 연결 주제에는 계정 검색/생성, 분기와 학년, 위치, 구역 말하기, 개인 귓속말, 채팅, 편지, 이벤트 마감과 결과, 상태, 기록, 수업, 인벤토리, 상점, 경매가 포함됩니다. 실제 전송·계정 보호·권한 확인·실시간 수신은 아직 연결되지 않았습니다.

분기별 입학 이력/학년 계산, 강제 이벤트 배정과 마감 처리, 오프라인 상태 변화, 수업·직업·상점·경매·인벤토리와 재화는 서버의 데이터베이스 및 시간 작업이 있어야 여러 플레이어에게 공통 규칙으로 적용할 수 있습니다. 규칙 세부값이 정해지지 않은 부분은 임의로 만들지 않았습니다. 실제 서비스로 전환할 때 백엔드 제공자와 연결 설정이 필요합니다.

검색과 가입 중복 확인은 지금 사용하는 브라우저 저장소만 대상으로 합니다. 전 세계 플레이어 사이의 아이디·캐릭터 이름 중복 방지, 실제 초대 코드 검증, 다른 기기 간 로그인/동기화는 보장하지 않습니다. 현재 구현은 비밀번호를 브라우저에 저장하는 데모이며 실제 운영용 인증으로 쓰면 안 됩니다.

수면 시간 선택은 분 단위이고, 피로 회복 규칙은 기존 5분당 1 감소 설정을 유지합니다. 현재 저장된 피로 수치는 코드가 변경하지 않습니다.

## 맵 임시 표시

맵의 실제 배경 그림은 아직 확정되지 않았습니다. 요청한 시제품 확인을 위해 내 방의 침대·책상·달력·문과 임시 이동점·상호작용점을 표시했습니다. 실제 학교 지도와 위치는 맵 확정 후 바꾸면 됩니다.
